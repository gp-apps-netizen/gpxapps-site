Inscrições de Eventos

Página de inscrição pronta para divulgar, pagamento por Pix automático e check-in na entrada lendo o QR Code do voucher.

  • Link de inscrição personalizado para cada evento
  • Voucher com QR Code enviado na hora para o participante
  • Pix automático: o dinheiro cai direto na sua conta
  • Check-in rápido pelo celular, com a câmera
  • Lista de inscritos, pagos e presentes em tempo real
  • Ideal para passeios ciclísticos, corridas, MTB, festas e cursos

Sem mensalidade para o organizador. A taxa de serviço é somada ao valor da inscrição e paga pelo participante.

Dúvidas

Perguntas frequentes

Preciso baixar algum aplicativo?

Não. Os sistemas funcionam pelo navegador do celular ou computador. No Android e no iPhone dá para adicionar o atalho à tela inicial e usar como um app.

Como recebo os pagamentos das inscrições?

Pelo Pix automático, o valor vai direto para a sua conta e a inscrição é confirmada sozinha. O voucher só é liberado depois que o pagamento é confirmado.

Quanto custa?

Inscrições de Eventos não tem mensalidade para o organizador. Bar e Salão têm mensalidade fixa. Chame no WhatsApp para receber os valores atualizados.

Posso testar antes de contratar?

Sim. Você usa por um período de teste com seus dados reais antes de decidir.

Meus dados ficam seguros?

Ficam armazenados em servidores do Google (Firebase), com acesso restrito por login. Cada cliente só enxerga os próprios dados.

Dá para personalizar para o meu negócio?

Sim. Nome, logo, cardápio, serviços, profissionais e regras do evento são configurados para você.

Vamos colocar seu negócio no celular?
